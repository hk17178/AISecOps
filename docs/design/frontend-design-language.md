## 0. 第一原则：摆脱"AI 味儿"

这是所有取舍的最高标尺。**禁止**出现以下"AI 生成器审美"：

❌ 紫色/靛蓝渐变、霓虹光晕　❌ 玻璃拟态（毛玻璃模糊卡片）　❌ 处处大圆角 + 浮夸投影
❌ emoji 当图标堆砌　❌ 居中 hero + 营销落地页排版　❌ 高饱和糖果色　❌ 默认 shadcn 紫主题

✅ **取而代之**：暖色纸感、克制大地色、衬线标题、硬朗细线、信息密度优先、久看不累。

---

## 1. 选定方向：暖纸·低刺激（Warm Paper）

从 5 个候选风格中选定（终端 / 瑞士 / 粗野 / 控制室 / **暖纸**）。选它的理由：

- **最护眼**：SOC 是天天盯屏场景，暖米底 + 低饱和大地色，比冷色 SaaS 久看不累。
- **最独特**：没人做暖色安全工具，天然摆脱 AI 味与"企业默认"。
- **够专业**：衬线标题 + 严谨网格，可信不轻浮。

## 2. 设计 Token

### 2.1 配色（语义化）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f4efe4` | 页面底（暖米） |
| `--paper` | `#fbf8f0` | 卡片/面板底 |
| `--paper2` | `#f7f2e7` | 次级面板/卡片背面/进度槽 |
| `--side` | `#efe9da` | 侧边栏底 |
| `--ink` | `#33312b` | 主文字 |
| `--dim` | `#8c887b` | 次要文字/标签 |
| `--line` | `#e0d9c8` | 边框/分隔线 |
| `--terra` | `#b0512f` | **主强调**（赤陶）：真威胁/严重/主按钮/品牌 |
| `--ochre` | `#bb8a3c` | 次强调（赭黄）：待研判/高/警示 |
| `--sage` | `#6d7d57` | 正向（鼠尾草绿）：正常/健康/中 |
| `--clay` | `#9a8266` | 中性（陶土）：低/边框按钮 |

**严重度配色**：严重=`terra` · 高=`ochre` · 中=`sage` · 低=`clay`
**研判配色**：真威胁=`terra` · 待研判=`ochre` · 误报=`dim`
> 全局**低饱和**，强调色只用于"真正要抓眼"的地方（真威胁/主按钮），不滥用。

### 2.2 字体

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 衬线 `.serif` | `Georgia,"Songti SC","Noto Serif SC",serif` | 品牌名、页面大标题、研判结论（增"分量感"） |
| 无衬线（正文） | `-apple-system,"PingFang SC","Songti SC",system-ui,sans-serif` | 正文、表格、表单 |
| 数字 | 上述 + `font-variant-numeric:tabular-nums` | 时间/置信度/金额等列对齐 |

> 不引入花哨网络字体（避免 AI 味 + 离线可用）。系统字体本身就够中性高级。

### 2.3 间距 / 圆角 / 边框 / 阴影

- **间距刻度**（px）：`6 / 10 / 14 / 18 / 22 / 26 / 34 / 40`
- **圆角**：卡片 `10` · 按钮 `6` · 徽标/胶囊 `10/20` · 进度条 `5`
- **边框**：主 `1px solid var(--line)`；证据/次要用 `1px dotted var(--line)`
- **阴影**：**几乎不用**。靠"细线 + 底色差"分层，不靠投影。**禁止**模糊大投影/玻璃感。

## 3. 动效规范（特效）

动效服务"信息表达"，不炫技。统一缓动、克制时长。

| 动效 | 规格 | 用途 |
|---|---|---|
| **卡片翻牌（悬停）** | `.flip:hover .inner{transform:rotateY(180deg)}`；`.6s cubic-bezier(.4,.2,.2,1)`；`preserve-3d` + `backface-visibility:hidden`。**鼠标移上翻面、移走自动翻回**（纯 CSS `:hover`，非点击） | 统计卡正面看数字，悬停看拆分明细 |
| **数字滚动计数** | 进页/路由切换时，统计数字从 0 缓动到目标（`~0.9s` easeOutCubic，保留千分位与前后缀 `¥`/`%`） | 数据"活"起来，强化数字感 |
| **进度条生长** | `.bar i` 宽度从 0 过渡到目标，`width .95s cubic-bezier(.3,.1,.2,1)` | 预算/降噪占比条 |
| **列表/卡片错峰淡入** | `fadeUp .5s both` + 逐项 `animation-delay`（卡片 80ms 步进 / 列表行 70ms / 证据 80ms） | 内容入场有节奏，不"啪"地全出 |
| **页面切换** | `fadeUp .34s ease`（opacity 0→1 + translateY 10px→0） | 菜单路由切换内容区 |
| **详情交叉淡入** | `opacity .25s`，换内容前加 `.swap`（opacity:0），220ms 后替换 | 点不同告警行，右侧详情切换 |
| **严重告警呼吸点** | 仅 `.d-crit`（严重/真威胁）：`pulse 2.4s` 赤陶色光环呼吸（box-shadow 扩散渐隐） | 把眼睛**只**引向最高危，克制不滥用 |
| **卡片悬停微抬** | `.card:hover`：`translateY(-1px)` + 边框转 `clay`，`.2s` | 可交互暗示 |
| **导航/行 hover** | `background .15s` | 悬停反馈 |
| **主按钮** | hover 加柔光 `box-shadow 0 3px 12px rgba(176,81,47,.25)`；按下 `translateY(1px) .1s` | 点击反馈 |
| **Toast** | 底部居中，`.3s` 滑入淡入，1.9s 自停 | 操作结果提示 |

> 原则：**单个动效 ≤ 0.95s**，缓动统一，不做弹跳/旋转/霓虹炫技（那是 AI 味）。呼吸点只给最高危一处。`悬停看明细` 提示文字与 `?flip=1` URL 参数仅供演示，正式版去掉。

## 4. 组件规范

| 组件 | 要点 |
|---|---|
| **翻牌统计卡** | 高 120px；正面：标签(dim) + 大数字(34px 600)；背面：明细列表(`.brk` 两端对齐)。强调数字用 `terra/ochre` |
| **告警行** | 三栏 `时间 / [严重度点+标题+来源] / [研判+置信度]`；hover 变色；选中 `.sel` 暖底 + 圆角 |
| **研判详情** | 顶 `⚑ 需 HITL` 胶囊标 + 衬线大标题 + meta；研判结论框（上下细线）；证据链(编号 + 引用来源)；底部主/次按钮 |
| **表格** | 表头 `dim` 小字大写；行用 `1px dotted` 分隔；数字列 `tabular-nums` |
| **胶囊 Pill** | 圆角 20px 描边；`ok=sage / warn=ochre / t=terra / 默认=dim` |
| **按钮** | 主按钮 `.go`：`terra` 实底白字；次按钮：`clay` 描边透明底。按下位移 1px |
| **徽标 Badge** | 导航计数：`terra`(默认) / `ochre`(.o)；V2 用 `.tagv2` 描边小标 |
| **空状态** | 居中大字符(衬线，opacity .5) + 一句说明（如威胁狩猎 V2 占位） |
| **Chat 气泡** | 用户气泡 `#e7dcc6` 右对齐；助手气泡 `paper`+描边左对齐；AI 回答附"引用来源"小字（呼应抑制幻觉 C-24） |

## 5. 信息架构（IA）· 菜单清单

## 5.1 登录页（独立于主壳）

登录页**不套侧边栏/顶栏**，是独立全屏页：

- 暖米底（`--bg`）全屏，**居中卡片**（`--paper` + `1px --line` + 圆角 10）。
- 卡片内：**衬线品牌 `AISECOPS`** + 副标"安全运营台" → 用户名 → 密码 → **主按钮 `登录`（terra 全宽）**。
- 底部一句克制提示（如"内部系统 · 仅授权人员"），**不要**插画/渐变/玻璃拟态/营销语。
- 错误提示用 `terra` 文案，输入框沿用主壳输入样式。
- 登录成功 → 进 `仪表盘`；失败 → 卡片内红字提示。
- RBAC 3 角色（管理员/分析师/普通查看）登录后由后端返回，决定可见菜单。

## 6. 布局

- **两栏壳**：侧边栏 `226px` 固定 + 主区自适应。
- **侧边栏**：品牌(衬线) → 分组(dim 小字大写) → 菜单项；选中项暖底 + 左侧 3px `terra` 竖条。
- **顶栏**：sticky；衬线页面标题 + 英文副标 + 右侧用户/时间。
- **内容区**：padding `26px 40px`；切换带 `fadeUp` 动画。
- **主从布局**：列表+详情用 `grid2 = 1.7fr / 1fr`，gap `34px`。
- **统计区**：4 列 `gap 18px`，翻牌卡高 120px。

## 7. 落地映射（React + shadcn/ui，dev-plan S4.5）

- 技术栈：React + TypeScript + Tailwind + shadcn/ui（dev-plan 既定）。
- **务必覆盖 shadcn 默认主题**：把上表 Token 写进 `tailwind.config` + CSS 变量（`:root`），**不要用 shadcn 默认紫**（那是最典型的 AI 味）。
- 字体：`font-serif` 映射 Georgia 栈用于标题/品牌/研判结论；正文用系统 sans。
- 动效：翻牌/过渡用 CSS（已在活样板验证），不引重型动画库。
- 数字列加 `tabular-nums`（Tailwind `tabular-nums`）。
- 组件优先复用活样板已验证的结构，再封装成 React 组件。
